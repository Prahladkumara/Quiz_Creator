# Quiz Creator

A Next.js and Firebase application for creating and saving multiple-choice quiz questions.

## Features

- Add a question with four answer choices
- Select the correct answer
- Save questions to Firebase Realtime Database
- View previously saved quiz questions
- Use the app on desktop or mobile screens

## Technologies

- Next.js
- React
- Firebase Realtime Database

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000/quiz`.

Configure Firebase with `NEXT_PUBLIC_FIREBASE_*` environment variables.
